# CodexCollector

## Visión del Producto
CodexCollector es una aplicación web fullstack que permite a desarrolladores organizar, valorar y descubrir recursos técnicos (libros, cursos, herramientas, fragmentos de código). Sirve como biblioteca digital personal y comunidad para compartir conocimientos.

## Propuesta de Valor Única
CodexCollector combina la gestión personal de recursos con elementos sociales (reseñas) y un sistema de búsqueda inteligente, demostrando capacidades técnicas fullstack en un contexto profesional relevante.
